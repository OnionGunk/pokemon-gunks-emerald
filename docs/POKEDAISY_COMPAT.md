# Gunk's Emerald and PokeDaisy

PokeDaisy and other companion apps read game memory at fixed addresses. Gunk's Emerald keeps the game code
`BPEE`, so emulators pick the right save type, which means a companion would take it for retail Emerald.

**Players:** use a companion build that lists Gunk's Emerald, or turn the companion off. Reading the moved
addresses below as retail Emerald shows wrong data.

## Telling it apart

- ROM header title (0x0A0, 12 bytes): `GUNK EM`. Retail has `POKEMON EMER`.
- The game code stays `BPEE`.

## Save data

The save layout differs from retail:
- PokemonStorage has 16 boxes, so its fields after the boxes (box names, wallpapers) moved.
- A slot uses 15 sectors.
- The Hall of Fame is in sector 30.
- There is no e-Reader Trainer Hill save.

The `Pokemon` / `BoxPokemon` format is unchanged, so every Pokémon stays legal.

Other data:
- The DexNav chain is in SaveBlock1 + 0x3D63, a retail padding byte.
- DexNav search levels are in PokemonStorage's free space.
